# My Expense Tracker

## Problem Solved
Many people struggle to track where their money goes. This Expense Tracker helps users record income and expenses daily to manage their budget better.

## Purpose of Project
This is my Final Independent Project for Moringa School. It demonstrates use of HTML5 semantic elements, CSS responsive design, JavaScript DOM manipulation, and localStorage.

## Features
- Add income and expense transactions
- View balance, total income and total expense
- Filter transactions by month
- View history and monthly report
- Data persists across pages using localStorage

## Technologies Used
- HTML5 (Semantic tags: header, nav, main, section, footer)
- CSS3 (Flexbox, Responsive with media queries)
- JavaScript (Vanilla JS)
- localStorage for data persistence
- GitHub for version control

## How to Run
1. Clone repo: git clone https://github.com/hexoblivion10-collab/Project2.git
2. Open index.html in any browser
3. No installation needed

## Known Limitations
- No yearly report, only monthly filter
- No edit transaction feature yet
